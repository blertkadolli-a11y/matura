Nëse x² − 5x + 6 = 0, cilat janë vlerat e x?
A
x = 2 dhe x = 3
B
x = −2 dhe x = −3
C
x = 1 dhe x = 6
D
x = 5 dhe x = 1
Përgjigja e saktë: A
Faktorizojmë: x² − 5x + 6 = (x − 2)(x − 3) = 0, prandaj x = 2 ose x = 3.
